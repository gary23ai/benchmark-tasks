# Reset and reproduction

Every recorded trial starts in a fresh process, which recreates the intact native scored joint. Restore all four declared body poses and zero velocities at reset, then return the unchanged robot to READY and let the runtime settle. After reset only gravity, contacts, passive hinge stops, the native break threshold and stock robot actions determine the task. Resetting an already broken joint within one simulator instance is unvalidated. [README.md](README.md) gives the install, full-budget scripted, counterexample-test and geometry-check commands. Historical gzip replay, cooking inspection and failed-attempt records support provenance; they are not prerequisites for a new run.

# Retire one worn utility-knife segment into a closed desktop disposal box

A desktop disposal box captures a spent segment during routine tool maintenance. The result is a shortened tip and one accounted-for segment in the closed box. The real product is documented by OLFA (DC-6). The scene starts with its guide selected and storage dock on the bench.
